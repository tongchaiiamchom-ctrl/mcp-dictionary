# MCP Dictionary

Bilingual (English / Thai) engineering & manufacturing terms dictionary.

A single-page web app that runs entirely in the browser. Data is stored in `localStorage`. Supports Excel import/export.

## Features

- Search terms by abbreviation, full name, Thai meaning, or description
- Categories: Engineering, Procurement, Production, Production control, Quality assurance, Safety and health, Other
- Add / edit / delete terms (soft-delete with 30-day trash)
- Search history
- Dark / light theme
- Language switch (EN / TH)
- Export to Excel (`.xlsx`)
- Import from Excel with preview & validation
- Offline-first (works without a server after first load)

## How to use

1. Open `index.html` in a browser, or
2. Use GitHub Pages (see below)

## GitHub Pages

Enable Pages in the repository settings (Settings → Pages → Source: Deploy from a branch → `main` / root).

After enabling, the site will be available at:

**https://tongchaiiamchom-ctrl.github.io/mcp-dictionary/**
