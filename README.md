# MCP Dictionary

Bilingual (EN/TH) engineering & manufacturing terms dictionary.

**Live site:** https://tongchaiiamchom-ctrl.github.io/mcp-dictionary/

## Features
- Search terms (EN/TH)
- Add / edit / delete
- Excel import/export
- Dark mode
- Offline (localStorage)

To restore the full app, replace `index.html` with the original file from the repo history or re-upload.
